(at this point our commits stays in our local machine)

Now before you push the commit, you need to authenticate for your git hub account and create the repo. 
There are two ways, either you manually create repo on github web OR use git hub cli. (check ChatGPT for authenticate and repo add via web)
Check gh –version on command prompt, if no output means, git hub CLI is not installed.
Install git hub cli using “winget install --id GitHub.cli” from command prompt. (see https://cli.github.com/ for latest)

Once git hub CLI is installed, use below process for authorization.

ai_learning_code_python> gh auth status
You are not logged into any GitHub hosts. To log in, run: gh auth login
